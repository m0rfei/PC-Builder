# Границы проекта

PC-Builder — локальное приложение для Windows (Windows-first) и одного пользователя.
Оно предназначено для ведения базы принадлежащего пользователю компьютерного
железа и создания виртуальных сборок ПК.

На текущем этапе подготовлены только пустое главное окно и базовая служебная
инициализация SQLite. Экраны комплектующих, редактирование характеристик,
конфигуратор, калькулятор блока питания и проверка совместимости пока не
реализованы. Также не реализованы сервер, облачная синхронизация и сетевые
сервисы.
