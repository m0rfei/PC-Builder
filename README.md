## О проекте

**PC-Builder** — настольное приложение для Windows, предназначенное для организации каталога компьютерных комплектующих, создания конфигураций ПК и предварительной оценки их совместимости и энергопотребления.

Идея появилась из желания собрать все необходимые сведения о комплектующих в одном месте. Вместо разрозненных заметок, таблиц и отдельных списков хотелось иметь собственную базу данных, в которой можно хранить характеристики компонентов, собирать из них конфигурации и быстро возвращаться к нужной информации.

Постепенно к первоначальной задумке добавились конструктор сборок, проверка отдельных параметров совместимости, калькулятор энергопотребления, архивирование записей и другие инструменты.

Проект разрабатывался прежде всего для собственных задач, поэтому его функциональность и интерфейс будут дорабатываться по мере использования и получения обратной связи.

## Реализованные возможности

### Каталог комплектующих

- Добавление и редактирование комплектующих.
- Хранение характеристик, заметок и изображений.
- Поддержка пользовательских характеристик.
- Поиск, фильтрация и сортировка записей.
- Архивирование и восстановление комплектующих.
- Создание копий существующих записей.

### Конструктор сборок

- Создание и сохранение конфигураций ПК.
- Добавление комплектующих в соответствующие категории.
- Указание количества компонентов.
- Работа с незавершёнными конфигурациями.
- Просмотр состава сборки и её текущего состояния.

### Проверка совместимости

В текущей версии реализованы базовые проверки:

- **Процессор и материнская плата:** соответствие сокетов.
- **Оперативная память и материнская плата:** соответствие типа DDR.
- **Кулер и процессор:** поддержка сокета процессора кулером.

Это только начальный набор правил. Программа не проверяет абсолютно все возможные ограничения и особенности комплектующих.

### Калькулятор энергопотребления

- Приблизительный расчёт энергопотребления сборки.
- Учёт мощности процессора и видеокарты, а также оценочных значений для остальных компонентов.
- Настраиваемые базовые значения энергопотребления.
- Расчёт рекомендуемого запаса мощности блока питания.

Результат является ориентировочным и не заменяет проверку реальных требований комплектующих и рекомендаций производителей.

### Локальное хранение данных

- Использование SQLite для хранения информации.
- Работа без обязательного постоянного подключения к интернету.
- Хранение пользовательской базы данных отдельно от файлов программы в установленной версии.

## Технологии

- **Python** — основной язык приложения.
- **PySide6** — графический интерфейс.
- **SQLite** — локальная база данных.
- **PyInstaller** — подготовка сборки для Windows.

## Установка

### Готовая версия для Windows

1. Откройте раздел [Releases](https://github.com/m0rfei/PC-Builder/releases).
2. Выберите последнюю опубликованную версию.
3. Скачайте ZIP-архив приложения из раздела файлов релиза. Не путайте его с автоматически создаваемыми GitHub архивами исходного кода (`Source code`).
4. Распакуйте ZIP-архив в отдельную папку.
5. Откройте распакованную папку и запустите `PC-Builder.exe`.

Не запускайте EXE непосредственно внутри ZIP-архива: сначала полностью распакуйте файлы.

При первом запуске программа создаёт пользовательскую базу данных в локальном профиле Windows. Поэтому база данных и пользовательские записи не должны находиться внутри архива с программой.

Если Windows или антивирус покажет предупреждение, не игнорируйте его автоматически. Убедитесь, что архив скачан из официального раздела релизов проекта, и самостоятельно оцените предупреждение.


## Где хранятся данные

Программа использует локальную базу SQLite. В установленной версии пользовательская база создаётся в каталоге:

```text
%LOCALAPPDATA%\PC-Builder\pc_builder.db
```

Это позволяет обновлять файлы приложения отдельно от пользовательской базы данных.

**Рекомендация:** периодически создавайте резервные копии базы данных. Перед ручным копированием желательно закрыть приложение. Не удаляйте файл базы данных, если хотите сохранить каталог и сборки.

При переносе программы на другой компьютер пользовательские данные автоматически не переносятся — базу данных необходимо перенести отдельно с учётом особенностей версии приложения.
